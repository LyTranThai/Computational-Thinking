Submission: 

- For reporting assignments 

   - Write the report in Markdown format. 

   - Submit both of the Markdown file and a rendered version (.pdf / .html) that displays the Markdown file correctly and attractively. 

- For coding assignments 

   - Submit the source code needed to build and run the program. Do not include build artifacts or dependency folders (e.g., node_modules/, bin/, obj/, virtual environments). 

   - For a complex project, also submit instructions that state your environment (operating system, language/compiler version, and dependencies), how to install or build the project, and the exact commands to run it. 

   - Finally, include screenshots of the program running on your own machine, showing the commands you ran and the resulting output.
